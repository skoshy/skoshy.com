Welcome to the very first blog post! This is written in markdown and will be rendered on the blog page.

This blog is built with Next.js and supports markdown posts with frontmatter. You can write your posts in markdown, and they will automatically show up on the blog index.

Markdown is a lightweight markup language that you can use to add formatting elements to plaintext text documents. It's easy to learn and widely used for documentation, blogging, and more.

Here's a quick example of a list:

- Item one
- Item two
- Item three

You can also add code blocks:

```
function helloWorld() {
  console.log('Hello, world!');
}
```

Or add links, like [Next.js documentation](https://nextjs.org/docs).
